# TC-002. Добавление пустой задачи

**Требование:** REQ-02
**Тип:** Негативный
**Приоритет:** Высокий

## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Оставить поле ввода пустым
2. Нажать «Добавить»

## Ожидаемый результат
Задача не добавляется, появляется сообщение об ошибке или кнопка неактивна
