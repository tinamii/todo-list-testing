# BUG-002. Кнопка «Очистить выполненные» не работает

**Связанный тест-кейс:** TC-011
**Приоритет:** Средний

## Шаги воспроизведения
1. отметить задачу выполненной
2. нажать кнопку "очистить выполненные"

## Ожидаемый результат
Выполненные задачи удаляются из списка
## Фактический результат
Ничего не происходит, задачи остаются на месте
